# 리드문 작성 스킬

제안서의 핵심 리드문을 **일괄 생성**하는 도우미입니다.
한 줄씩 쓰지 않고, 전체 구조를 파악한 뒤 한 번에 출력합니다.

## 워크플로우

```
Phase 1: 설정 → Phase 2: 호흡 맞추기 → Phase 3: 일괄 생성 → Phase 4: 인간 수정
```

---

## Phase 1: 설정

사용자에게 다음 정보를 요청합니다:

### 1-1. 기본 정보
```
제안서 리드문 일괄 생성을 도와드릴게요!

먼저 기본 정보를 알려주세요:

1. **산업/분야**: (예: 환경, 사회서비스, 핀테크, 헬스케어...)
2. **참고 자료**: (기존 PPT, 회의록, 소개서 등 - 없으면 "없음")
```

### 1-2. 슬롯 정의
```
다음 변수들의 값을 알려주세요:

• ORG (수행사): MYSC
• PARTNER (발주처/협력기관): 중앙사회서비스원
• TARGET (대상): 사회서비스 스타트업
• PROGRAM (프로그램명): 소링아
• 기타 필요한 변수...
```

### 1-3. 파트 구성
```
제안서 구조를 알려주세요:

예시:
- INTRO (제안사 소개): 2장
- OVERVIEW (사업 개요): 3장
- DETAIL (상세 내용): 8장
- PLAN (수행 계획): 4장
- EFFECT (기대효과): 2장

총 19장
```

---

## Phase 2: 호흡 맞추기

2-3개 샘플을 먼저 생성하여 스타일/톤을 조율합니다.

```
샘플 리드문을 생성했습니다. 이 톤이 맞나요?

[샘플 1 - INTRO]
"MYSC는 사회혁신 전문 액셀러레이터로서 임팩트 투자와 체계적 육성을 통해
소셜벤처의 지속 가능한 성장을 지원합니다."

[샘플 2 - OVERVIEW]
"본 사업은 중앙사회서비스원과 협력하여 사회서비스 분야 스타트업의
역량 강화와 투자 유치 활성화를 목표로 합니다."

피드백:
- [ ] OK, 이 톤으로 진행
- [ ] 더 간결하게
- [ ] 더 풍부하게
- [ ] 기타 (직접 입력)
```

---

## Phase 3: 일괄 생성

확정된 스타일로 전체 리드문을 한 번에 출력합니다.

```
=== 전체 리드문 (19장) ===

[1] INTRO - 제안사 소개
"MYSC는 사회혁신 전문 액셀러레이터로서 임팩트 투자와 체계적 육성을 통해
소셜벤처의 지속 가능한 성장을 지원합니다."

[2] INTRO - 주요 실적
"2015년 설립 이후 150개 이상의 소셜벤처를 육성하고 500억 원 이상의
후속 투자를 유치하는 성과를 달성했습니다."

[3] OVERVIEW - 사업 목표
"본 사업은 중앙사회서비스원과 협력하여 사회서비스 분야 스타트업의
역량 강화와 투자 유치 활성화를 목표로 합니다."

...

[19] EFFECT - 기대효과
"사회서비스 분야 투자 생태계 활성화와 지속 가능한 소셜벤처 육성
모델을 확립합니다."

===

위 내용을 복사하여 사용하시고, 필요한 부분만 수정해주세요!
```

---

## Phase 4: 인간 수정

- 전체 출력물을 복사
- 디테일한 부분만 직접 수정
- 완료!

|------|------|------|

| PARTNER | 발주처/협력기관 | 중앙사회서비스원 |
| TARGET | 대상 | 사회서비스 스타트업 |
| PROGRAM | 프로그램명 | 소링아 |
| EFFECT | 효과/목표 | 투자 유치 활성화 |
| METHOD | 방법 | 액셀러레이팅 |

| AMOUNT | 금액 | 1억원 |

## 제약 조건

리드문은 **아이디에이션 제공**이 목표입니다. 풍부한 내용을 2-3문장으로 구성합니다:

| 항목 | 조건 | 비고 |
|------|------|------|
| 길이 | **100-120자** (필수) | 충분한 내용 전달 |
| 문장 수 | **2-3문장** 구성 | 단문 금지 |
| 엔딩 | "합니다.", "입니다.", "했습니다." 등 | 경어체 |
| 구성 | 핵심 주장 + 뒷받침 내용 | 논리적 전개 |
| 개행 | 사용 금지 (한 줄) | 필수 |
| 금지어 | "펠로우"→"펠로", "기업가 정신"→"임팩트 앙트프러너십" | 필수 |

**원칙**: 단순 요약이 아닌 **아이디에이션 제공**이 목표입니다. 사용자가 내용을 보고 방향을 잡을 수 있도록 구체적으로 작성합니다.

## 참고 데이터 활용

사용자가 제공한 참고 데이터는 다음과 같이 활용됩니다:

1. **기존 제안서 파일**: 문체와 용어 추출
2. **샘플 리드문**: Few-shot 예시로 활용
3. **회사 소개**: 고유 표현 및 키워드 추출

참고 데이터가 없는 경우, 내장된 예시 데이터를 사용합니다:
- `learning_data/skill_examples/`
